# Simulation code

This directory contains the R code for the methodological simulation study.

The code will be organized by function rather than by output location. The cleaned scripts developed for the manuscript will be added here while preserving their execution order where useful.

Planned components include:

- data-generating mechanisms and calibration;
- estimators and method-specific helpers;
- primary simulation runs;
- sensitivity analyses;
- result combination and summarization;
- manuscript figures and tables;
- simulation quality-control checks.

Large repetition-level outputs should not be committed to GitHub. Only compact manuscript-facing summaries, quality-control outputs, and figures should be retained in `results/`.
