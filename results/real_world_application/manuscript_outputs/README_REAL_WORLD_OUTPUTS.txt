MIDUS REAL-WORLD APPLICATION

This folder keeps the main tables, figure, and QC results from the MIDUS application.

Figure:
  figures/Figure_real_world_method_comparison_with_annotations.pdf
    Annotated coefficient and 95% CI plot used as Figure 6 in the manuscript.

Tables and data:
  tables/Table3_characteristics_by_phase2.csv
    Characteristics by Phase-2 RNA-marker availability.

  tables/Table3_standardization_qc.csv
    Standardization checks for variables used in Table 3.

  tables/Table4_phase2_correlations_display.csv
    Lower-triangle correlation table used for display.

  tables/Table4_phase2_correlations_r.csv
  tables/Table4_phase2_correlations_p.csv
    Correlation coefficients and p-values for Table 4.

  tables/Table_real_world_application.csv
  tables/Table_real_world_application_unrounded.csv
    Rounded and unrounded results for the six analysis methods.

  tables/real_world_gtsummary_table_qc.csv
    Checks for the generated manuscript tables.

  diagnostics/real_world_weight_diagnostics_summary.csv
    IPW/AIPW weight diagnostics, including effective sample size.

During analysis, scripts 45 and 47 can also create Word files, alternate table layouts, PNG versions, and comparison tables. Those extra working files are not included here because they are not needed for the paper.

Figure 6 and the data used for Tables 3–4 are also copied to results/manuscript/main/ so they are easy to find.
