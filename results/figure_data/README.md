# Figure data

This directory contains compact machine-readable data and metadata used to support the simulation figures.

- `figure_manifest.csv` records the complete generated figure library.
- `manuscript_candidate_regimes.csv` defines the weak, MIDUS-like, and strong candidate regimes.
- `runtime_overview_data.csv` contains the data used for the runtime diagnostic.

Primary failure rates are stored canonically in `results/summary/primary_failure_rates.csv`; an exact duplicate is not retained here.

Final reader-facing manuscript figures are stored under `results/manuscript/`.
