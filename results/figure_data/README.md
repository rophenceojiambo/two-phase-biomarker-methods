# Figure data

This folder contains the small data files used to organize and reproduce the simulation figures.

- `figure_manifest.csv` lists the full set of figures generated by the figure script.
- `manuscript_candidate_regimes.csv` defines the weak, MIDUS-like, and strong settings used when choosing figures for the paper.
- `runtime_overview_data.csv` contains the data used for the runtime plot.

The primary failure-rate file is kept in `results/summary/primary_failure_rates.csv`; a second copy is not kept here.

The figures used in the manuscript are in `results/manuscript/`.
