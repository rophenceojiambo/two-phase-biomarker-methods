# Results

This directory is for compact, manuscript-facing, disclosure-safe outputs.

Appropriate tracked outputs include:

- summarized simulation performance measures;
- Monte Carlo standard errors;
- simulation failure and convergence summaries;
- quality-control summaries;
- final tables;
- final figures;
- aggregate empirical-application results approved for public release.

Do not commit:

- raw repetition-level simulation outputs;
- SLURM chunk files;
- checkpoints;
- participant-level MIDUS data or intermediate objects.

Large or regenerable outputs should remain outside Git and be recreated from the source code.
