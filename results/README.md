# Results archive

This directory is reserved for compact, manuscript-facing, disclosure-safe outputs from the completed analyses.

## Recommended files to archive

### Primary simulation

From `results/summary/`:

- `primary_rsimsum_tidy.csv`
- `primary_performance_wide.csv`
- `primary_type1_error.csv`
- `primary_failure_rates.csv`
- `primary_runtime.csv`
- `primary_phase2_diagnostics.csv`
- `primary_weight_diagnostics.csv`

From `results/tables/`:

- `table_ADEMP_design.csv`
- `table_main_MIDUS_like_and_stress.csv`
- `table_type1_reference_scenarios.csv`
- `table_phase2_diagnostics_all_scenarios.csv`
- `table_weight_diagnostics_all_scenarios.csv`
- `table_deterioration_flags.csv`
- `table_deterioration_summary_by_method.csv`
- `table_runtime_overview.csv`
- `table_failure_overview.csv`

Also retain the final manuscript figures selected from `results/figures/03_final_manuscript/`, their underlying figure data, and the figure manifest.

### Sensitivity analyses

For each sensitivity analysis, archive the compact summary/performance CSVs and the QC/comparison CSVs used to support the manuscript conclusions. The main groups are:

- AIPW robustness
- strong AIPW misspecification
- empirical-residual generation
- phase-2 MCAR
- FCS predictive mean matching
- IPW weight capping

Raw chunk files, checkpoints, scenario-level RDS files, and rsimsum object files are not needed in the public repository.

### MIDUS real-world application

After disclosure review, appropriate aggregate outputs include:

- `midus_real_world_sample_summary.csv`
- `midus_real_world_marker_missingness.csv`
- `midus_real_world_result_qc.csv`
- `midus_real_world_method_results.csv`
- `midus_real_world_weight_diagnostics.csv`
- final manuscript tables generated by scripts 45 and 47
- final real-world figures generated by script 45
- correlation and method-comparison CSVs used in the manuscript

Any aggregate MIDUS output should be reviewed for compliance with the applicable data-use and disclosure requirements before it is made public.

## Do not archive

Do not commit:

- raw or analysis-ready participant-level MIDUS data;
- participant identifiers;
- participant-level intermediate exports;
- raw Monte Carlo chunk files;
- checkpoints;
- scenario-level estimate RDS files;
- cached simulated datasets;
- SLURM logs or scratch files.

The repository `.gitignore` blocks the most common restricted and regenerable file types.
