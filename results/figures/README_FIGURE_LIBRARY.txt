MIDUS TWO-PHASE SIMULATION — FIGURE LIBRARY

The complete figure library is generated by 09_make_simulation_figures.R.

Generated-library structure:
  01_full_factorial/
    Complete R_A^2 x R_Y^2 figure library.

  02_manuscript_candidates/
    Weak, MIDUS-like, and strong auxiliary-information candidate figures.

  04_diagnostics/
    Runtime diagnostics; failure rates are stored as data because all primary failures were zero.

Final manuscript-facing figures:
  results/manuscript/main/figures/
    Figures 1–6 exactly as numbered in the manuscript.

  results/manuscript/supplementary/figures/
    Supplementary Figures S1–S10 exactly as numbered in the manuscript.

The former results/figures/03_final_manuscript/ selection has been retired so that manuscript figures are no longer split into arbitrary core, stress, and supporting folders. In particular, power is a main-text result (Figure 5) and is stored with Figures 1–4 and Figure 6.

Figure-generation conventions retained in the manuscript figures include:
  - common relative-precision and power scales;
  - reference lines for SE ratio, coverage, Type I error, and power;
  - fixed method order: Naive, CCA, FCS-MI, JM-MI, IPW, AIPW;
  - consistent Phase-2 fraction notation using phi_2;
  - PDF-safe plotmath labels;
  - cairo_pdf vector output.

Machine-readable figure metadata and source summaries are retained under results/figure_data/ and results/summary/.
